# Screenshots

Drop your own captures here using these exact filenames and the gallery in the main
`README.md` will pick them up automatically:

| Filename | Page | Suggested viewport |
|---|---|---|
| `landing.png` | `/` (hero section) | 1440×900 |
| `features.png` | `/` (bento feature grid) | 1440×900 |
| `register.png` | `/register` | 1440×900 |
| `login.png` | `/login` | 1440×900 |
| `dashboard.png` | `/dashboard` (after logging in) | 1440×900 |
| `dashboard-mobile.png` | `/dashboard` | 390×844 (mobile) |

## How to capture them

1. `npm run dev` and open the app in Chrome.
2. Open DevTools → Command Menu (`Cmd/Ctrl + Shift + P`) → **"Capture full size screenshot"**
   for a clean, full-page PNG with no browser chrome.
3. For the mobile shot, toggle device toolbar (`Cmd/Ctrl + Shift + M`), pick an iPhone
   preset, then capture the same way.
4. Save each file into this folder with the filename from the table above.
